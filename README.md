# ArbiterSort AI (`ArbiterHacks2026`)

**Real-Time Spectral-Vision Waste Contamination Detector, Polymer Classifier & Municipal Circular Routing Engine** built for **Arbiter Hacks V1 (Theme Track: "Rethinking Waste")**.

## Repository Structure
- `index.html` — Self-contained interactive 60 FPS Optical/NIR Conveyor Sorter, Spectral Absorbance Plotter, and Circular Waste-to-Resource Router.
- `arbiter_waste_engine.py` — Python multi-modal spectral classifier & EPA WARM circular valuation engine.
- `DEVPOST_SUBMISSION.md` — Complete Devpost submission writeup & architecture diagram.
